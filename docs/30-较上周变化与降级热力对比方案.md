## 2. 口径（写死，便于测试）

### 2.1 较上周变化

对每个「本周合格小区」（`temperature` 非空的最新行）：

1. 取它在**当前最新行之前、最近一条 `temperature` 非空的行**作为上期（`prev`）；
2. `delta = 本周温度 - 上期温度`；
3. 没有上期行 → 该小区 `delta = None`，计入 `delta_insufficient`。

城市级：

| 字段 | 定义 |
|---|---|
| `temperature_delta` | 有 delta 的小区均值，保留 1 位；一个都没有则 `null` |
| `delta_count` | 参与均值的小区数 |
| `delta_insufficient` | 合格小区里没有上期温度的个数 |
| `delta_insufficient_ratio` | `delta_insufficient / count`（`count` 为合格小区数），保留 3 位 |

> **待确认（唯一口径分歧点）**：这里的「上周」取**上一期观测**（该小区上一条有温度的周），
> 不是日历上周 `W-1`。原因：数据是周更快照且稀疏，严格按日历上周时几乎所有小区都会是
> null，功能不可用。若 docs/27 明确要求日历上周，请 Leader 指出，我改为严格口径。

### 2.2 分区温度列表

城市对象新增 `districts` 数组，逐区聚合（与城市级同口径）：

```json
{"district": "朝阳", "temperature": 52.3, "count": 1200, "total": 1500,
 "insufficient": 300, "insufficient_ratio": 0.2}
```

排序：`temperature` 降序（null 排最后），同值按 `district` 升序。
区名为空的小区归到 `"未分区"`。

### 2.3 同板块均价

`GET /api/xiaoqu/{id}` 的响应附加：

```json
"plate_stats": {"plate": "望京", "avg_price": 52300.0, "count": 12,
                "price": 55000.0, "diff_pct": 0.0516}
```

- `avg_price`：同城同板块、各有价格的最新一期均价的算术平均（只计 `price` 非空）；
- `count`：参与平均的小区数（含本小区）；
- `price`：本小区最新一期价格（无则 `null`）；
- `diff_pct`：`price / avg_price - 1`，任一缺失则 `null`；
- 板块为空或无同板块数据 → `plate_stats = null`。

## 3. 涉及文件与修改点

### 3.1 `backend/shikar/overview.py`

1. `_summary_item` 不动（榜单字段保持）。
2. `compute_overview` 的循环里额外记录每个合格小区的 `district` 与 `prev_temp`：
   - 新增 `_prev_row(series)`：从最新行往前找第一条 `temperature` 非空且 `week` 小于最新行的行；
   - 城市累计器增加 `delta_sums: list[float]`、`delta_missing: int`；
   - 区累计器 `districts[city][district]` 内累计 `temps / count / total / insufficient`。
3. 城市对象新增 `temperature_delta`、`delta_count`、`delta_insufficient`、
   `delta_insufficient_ratio`、`districts`（字段只增不改）。
4. docstring 与返回结构说明同步。

### 3.2 `backend/shikar/storage.py`

新增 `plate_price_stats(conn, city, plate)`，用一条聚合 SQL 取「同城同板块、各自最新一期、价格非空」的
`COUNT(*)` 与 `AVG(price)`；返回 `{"avg_price": float|None, "count": int}`，`plate` 为空直接返回 `None`。
具体 SQL 以「每个小区最新 week」关联，避免把不同期次混在一起平均。

### 3.3 `backend/shikar/api.py`

详情分支（`len(segments) == 1`）改为：取到小区行后构造
`dict(row) + {"plate_stats": ...}`；`plate_stats` 里并入本小区最新价与 `diff_pct`。
**不新增路由**，其余端点不动。

### 3.4 `web/app.js` + `styles.css`

1. 城市卡片：温度下方加一行 `较上周 +1.2`（无 delta 时显示「上周无可比数据」）；
   在榜单前插入「分区温度」列表（区名 + 温度 + 不足比例），最多展示 8 行，超出折叠为「共 N 个区」。
2. 详情页 `renderDetailHead`：在位置行下方加一行同板块文字：
   「同板块 12 个小区均价 5.23 万/㎡ · 本小区 5.50 万/㎡（高 5.2%）」；
   `plate_stats` 为 null 时不渲染。
3. `styles.css` 增加 `.city-delta`、`.district-heat`、`.plate-compare` 三个小样式。

## 2. 口径落实（docs/32）

- **候选来源**：`/api/catalog?city=&price_min=&price_max=&price_week=&stage=`（现有参数）。
- **过滤**：同城、排除自身、`data_points >= 2`、价带内二次校验。
- **排序**：`|温度差|` → `|价格差|` → `id`；无温度的候选排最后。
- **理由**：模板只引用真实字段，末尾带 `期次 latest_week`；当前小区 dp<2 时**不出现任何温度话术**，改为同区 + 同价带、只说价格。
- **数量**：3–5 条，不足则空态「暂无相似小区」，不硬凑。

## 4. 两个已知坑

1. 稀疏小区 `temperature=50` 是默认值：候选过滤 `data_points>=2`，当前小区自身 dp<2 时整段降级。
2. seed 库每 plate 只有 1 个小区：测试全部自建同城同价带多小区数据，未依赖 seed。

## 5. 线上预期

当前真实库 100% 小区温度为空（#36 门槛），因此线上大概率走降级分支：同区 + 同价带、理由只说价格。这是预期行为。

## 6. 风险 / 回退

- 仅前端新增文件与展示；无 schema、无依赖、无网络调用。
- 回退：删除 `renderSimilarSection` 调用或 revert 单提交即可，不影响其它页面。

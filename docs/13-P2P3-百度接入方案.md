# P2/P3 百度接入方案与现状（2026-11-10）

## 0. 结论
- 用户提供的**百度地图 AK 已验证可用**：地点检索(place/v2/search)、地点联想(place/v2/suggestion)、驾车(directionlite/v1/driving)、公交(directionlite/v1/transit) 均 `status:0`。Key 存于本地 `.secrets/baidu_ak.txt`（已 gitignore，**不入库**）。
- **重要限制**：百度地点检索对单条 query 的返回量有明显上限（实测北京“小学/中学/高中/医院/高铁站”分别约 127/128/114/135/25，按区（海淀/朝阳/和平）查询也只有 ~120–130；说明是**单 query 结果上限**而非区域细分能突破）。
  → 要做到“较全覆盖”，必须**网格分块（矩形区域检索）或按关键词/街道细分后合并去重**，请求数与配额显著上升。

## 1. 坐标与距离
- 百度 POI 返回 **BD09** 坐标；本仓库小区坐标为 **WGS84**、地铁为 WGS84。
- 距离计算前需统一：WGS84 ↔ GCJ02 ↔ BD09 转换（纯 Python 实现，无第三方）。
- 距离仍为**直线距离**；通勤时间另用路径规划 API。

## 2. 数据模型（沿用既有设计）
- `poi(id, type, subtype, name, grade, lat, lng, district, source, version)`（type: school/hospital/hsr；school.subtype: primary/middle/high；hospital.grade: 三甲/二甲/未知）
- `community_poi(community_id, poi_id, distance_km)`，索引 `(poi_id, distance_km, community_id)` 供「周边 Top20」。
- `community_features` 物化宽表：各阶段最近学校距离、医院最近距离/是否含三甲、高铁最近距离、更新时间。
- `commute_cache(origin, dest, direction, mode, period, provider, duration_s, distance_m, expires_at)`。

## 3. 采集策略（需选择）
| 方案 | 做法 | 覆盖 | 请求/配额 | 建议 |
|---|---|---|---|---|
| **A 快速版** | 每市/每区每类取百度前 ~120–200 条 | 有限（覆盖核心 POI） | 低（每类每区 ~1–10 页） | 先跑通全链路 |
| **B 网格版** | 城市按 ~0.05°–0.1° 网格矩形分块检索，分页取满后按 uid 去重合并 | 较全 | 高（数千请求，受日配额限制，需分批多日） | 追求完整覆盖时再做 |
| C 分阶段 | 先 A 打通，再对缺口大的类别/区做 B 补全 | 逐步提升 | 中 | **推荐** |

## 4. 接口规划
- `GET /api/schools?stage=&city=`、`GET /api/hospitals?grade=&city=`、`GET /api/hsr?city=`
- `GET /api/poi/{poi_id}/communities?limit=20`（按 distance 升序）
- `GET /api/catalog` 扩展 `stage/school_max/grade/hospital_max/hsr_max`（P2-02 现在返回 400，需实现）
- `GET /api/commute?fromA=&fromB=&mode=&w=&limit=`（A/B 具体地点先用 `place/v2/suggestion` 解析）

## 5. 通勤（P3）与成本
- 驾车/公交用 `directionlite`；每个候选需 2 次 OD（到 A、到 B）。
- 先用 P1/P2 条件粗筛 ≤200 候选，再算；结果写 `commute_cache`（按方向/坐标/方式/时段/供应商/策略，含 TTL）。
- 权重：`w·tA+(1−w)·tB`；50/50 叫「等权」；可选 `max(tA,tB)`「最慢一方」。
- 配额/计费以百度控制台为准，需设日预算上限，超限返回明确错误。

## 6. 分期
1. **P2a**：学校（小学/初中/高中）+ 医院（等级/距离）采集→关系表→宽表→API→前端「学校/医院」菜单与抽屉筛选。
2. **P2b**：高铁站 + 明细/Top20 + 筛选。
3. **P3**：地点解析、驾车/公交路径、候选管理与缓存、加权排序。

## 完整要求

1. 地铁沿线查找小区：城市、多线路、站点、距站与距线路口径、距离阈值及排序。
2. 小区附近医院、学校（小学/初中/高中）、高铁站数据；阶段/等级/距离/指定设施筛选；设施明细独立菜单；设施周边小区距离 Top20；支持带回首页组合查询。
3. 双点通勤：输入两个具体地点、驾车或公交、A/B 权重、50/50 等权与最慢一方策略；展示双方时间与加权时间；按得分排序。
4. 首页三主筛选 + 更多条件分组抽屉 + chips + 分层结果 + 手机弹层，沿用纸面年鉴视觉。

先完成 P1 真实数据与界面，再推进学校/医院/高铁和通勤。零成本数据优先；Key 或属性名单缺失时先做离线导入、适配层和测试，不伪造生产数据、不自动申请 Key 或进行付费调用。

沿用 SQLite + Python 标准库 + 原生前端；规范化明细关系 + 物化宽表，不引入不必要的框架。坐标系先核实；空间距离不等于通勤；附近学校不等于对口；历史价格显示期次；医院等级和距离须同一 POI 满足；多线路按匹配线路查询，不能只查全局最近线路。
